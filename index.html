用户视频数据可视化

GET /api/userprofile/videolist · 数据来源: openms.top

使用说明
  • 输入用户 ID 后点击「开始探索」。首次访问该用户需要联网，之后数据缓存在本地。
  • 「统计概览 / 数据明细 / PB 网格」查看单个用户，「互啄 PK」比较两个用户，「奖牌榜 / 奖牌图 / PB 总榜 / 前端成绩」跨用户排行。
  • 「前端成绩」的取前 N 名与软实力权重可在「设置」中调整；软实力以 NT 锚点为 100 基准，NT 由各列前若干名用户的均值计算。
  • 「帕累托线 / 分档」需先在「缓存管理」中重算支撑线；「PB 总榜」的加权平均列需先在「设置」中配置权重；「前端成绩」的取前 N 名可在「设置」中调整，修改后自动重算。
  • 「缓存管理」可批量加载用户、一键重算 PB / 排行 / 支撑线 / 前端成绩、同步用户信息。缓存永久有效，需手动刷新。
  • 图表库 Chart.js 从 CDN 加载，首次访问需要联网。
