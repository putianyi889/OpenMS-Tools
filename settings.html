前端成绩 - 取前 N 名

每个用户的 9 个桶（bt/bb/bs · it/ib/is · et/eb/es）取前 N 名的均值。 修改后将立即重算所有用户的前端成绩，并自动刷新 NT 锚点。

NT 锚点 - 取前 N 名

对前端成绩的九列各取前 N 名求平均，结果即 NT 锚点（软实力 100 的基准）。 点击「保存并重算」总是重新计算一次 NT。重算前端成绩时也会自动刷新 NT。

软实力权重

每级别的软实力 = 该级别 time/bvs/stnb 三个软实力的加权平均； 总软实力 = 三个级别软实力的加权平均（等级权重 = 该等级三个权重之和）。 总和不必为 1。

B 级权重

输入 JSON 数组，下标为 bv（第一个位置是0bv）。 值是该 bv 的权重，用于 PB 网格的加权平均列。总和不必为 1， 算法会按 Σ(v·w)/Σ(w) 归一化。

同 B 级，下标为 bv。
